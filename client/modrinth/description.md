# Kromvia Client

A PvP and quality-of-life client mod with its own title screen, a module menu and a drag-and-drop HUD editor. One jar per Minecraft version, from **1.15.2 to 26.3**, on Fabric, plus Forge and NeoForge for 1.20.6 and newer. No Fabric API needed.

Press **Right Shift** in game to open the module menu.

## Modules

**PvP**: keystrokes, CPS/FPS, armour status, potion effects, attack indicator, hitboxes, target marker, hit bubbles, hit colour and particles, visible damage, 1.7 animations.

**HUD**: detailed armour bar, effect timers, scoreboard tweaks, vanilla HUD toggles. Every element can be moved and scaled in the HUD editor.

**Visuals**: motion blur and saturation (1.21.2+), block outline, crosshair, custom FOV, hand position and sway, bobbing, glint colour, trails, jump circles, China hat, weather and time changer, no fog, gamma per dimension.

**Utility**: freelook (hold Alt), freecam, better chat (timestamps, filter, macros F6–F9, image previews), nametags, inventory scale, easy place, sound volumes, IRL weather.

Settings are saved per profile, so you can switch between a PvP setup and a building setup in one click.

## Version notes

- 1.16.x and 1.15.2 have the core modules and HUD, but no world effects (trails, motion blur, outfits and so on).
- Motion blur and saturation need 1.21.2 or newer.

## Network use

The mod only connects to the internet for these features, and only while they are on:

- **IRL Weather** fetches the weather for your IP's location from `wttr.in`.
- **Chat image previews** (off by default, Chat Tools) download images from links in chat when you hover them, so the image host sees your IP.

No telemetry, no accounts.

## Kromvia Launcher

The [Kromvia Launcher](https://kromvia.com) ships this client built in and adds friends, parties, an account switcher, cosmetics, music controls and lyrics on top.
